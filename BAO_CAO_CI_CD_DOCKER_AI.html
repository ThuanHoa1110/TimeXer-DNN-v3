1.1. Phân tích Ý 1: Triển khai CI/CD cho bài toán AI

Trong quy trình phát triển phần mềm chuẩn mực, CI (Continuous Integration) và CD (Continuous Delivery) giúp tự động hóa khâu kiểm thử và phát hành. Tuy nhiên, đối với bài toán Trí tuệ nhân tạo (AI/Deep Learning), CI/CD có những nét đặc thù mang tính quyết định:

  • Data Pipeline & Schema Testing: Kiểm tra tính toàn vẹn của dữ liệu chuỗi thời gian khí tượng đầu vào (tần số 5 phút, độ dài Lookback $L=96$, không bị khuyết thiếu NaN, đủ các biến ngoại sinh bức xạ, gió, độ ẩm, áp suất).
  • Deep Learning Model Architecture Testing: Kiểm tra luồng Tensor Flow qua mạng TimeXer_DINOv3, cơ chế LayerScale ($\gamma=10^{-5}$), Multi-Head Cross-Attention và chiều kích thước đầu ra $MS$ [Batch, 24, 1].
  • Composite Loss & Gradient Flow Testing: Kiểm thử hàm mất mát DINO-v3 kết hợp 3 thành phần ($\mathcal{L}_{\text{task}} + \lambda_{\text{distill}}\mathcal{L}_{\text{distill}} + \lambda_{\text{gram}}\mathcal{L}_{\text{gram}}$) và đảm bảo gradient lan truyền ngược (backward pass) thành công.
  • Model Serving Verification: Nạp file trọng số thật (checkpoints/timexer_dinov3_best.pth) và kiểm tra module suy luận TimeXerInferenceEngine dự báo thành công 24 bước thời gian.

1.2. Phân tích Ý 2: Build Docker Image cho Model AI & Public lên Docker Hub

Mô hình AI cần môi trường runtime đồng nhất (Python 3.10, PyTorch, Scikit-learn, Pandas). Việc đóng gói Docker Image đảm bảo tính di động (portability) và khả năng triển khai tức thì:

  • Tối ưu hóa kích thước: Sử dụng Base Image python:3.10-slim và bánh xe PyTorch CPU wheel tối ưu, giúp giảm kích thước từ >3GB xuống chỉ còn vài trăm MB.
  • Tệp .dockerignore: Loại bỏ các tệp dữ liệu thô kích thước lớn (file 74MB real_weather_large_dataset.csv), bộ nhớ đệm __pycache__ và môi trường ảo .venv khỏi build context.
  • Public Image lên Docker Hub: Thiết lập quy trình tự động đẩy Image lên Docker Hub công khai (thuanhoa1110/timexer-dinov3-ai:latest) để người dùng hoặc hội đồng chấm thi có thể kéo về chạy với 1 câu lệnh duy nhất.

Bước 2: Cấu hình GitHub Actions CI Pipeline (.github/workflows/ai_ci_cd.yml)

# Trích đoạn Job AI-CI trong .github/workflows/ai_ci_cd.yml
name: AI MLOps CI/CD Pipeline & Docker Hub Delivery
on:
  push:
    branches: [ main, master ]
  pull_request:
    branches: [ main, master ]

jobs:
  ai-ci-pipeline:
    name: "CI: Code Linting, PyTorch Model Verification & AI Tests"
    runs-on: ubuntu-latest
    steps:
      - name: 1. Checkout Mã Nguồn
        uses: actions/checkout@v4
      - name: 2. Cài đặt Python 3.10
        uses: actions/setup-python@v5
        with: { python-version: "3.10", cache: "pip" }
      - name: 3. Cài đặt Thư viện & PyTorch CPU
        run: |
          pip install flake8 pytest
          pip install torch --index-url https://download.pytorch.org/whl/cpu
          pip install -r requirements.txt
      - name: 4. Kiểm tra Cú pháp & Code Style (Flake8)
        run: flake8 . --count --select=E9,F63,F7,F82 --show-source --exclude=.venv
      - name: 5. Chạy Kiểm định Backbone DINO-v3
        run: python run_test_dinov3.py
      - name: 6. Chạy Bộ Kiểm thử Toàn trình AI Test Suite
        run: python -m unittest tests/test_ai_pipeline.py -v

🐳 3. THỰC HIỆN CHI TIẾT Ý 2: BUILD DOCKER IMAGE & PUBLIC DOCKER HUB

Bước 1: Thiết kế Dockerfile Chuẩn AI Serving

FROM python:3.10-slim
LABEL maintainer="Nguyen Thuan Hoa "
ENV PYTHONUNBUFFERED=1 PORT=8080 STREAMLIT_SERVER_PORT=8501

RUN apt-get update && apt-get install -y --no-install-recommends curl \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app
COPY requirements.txt /app/requirements.txt
RUN pip install --no-cache-dir torch --index-url https://download.pytorch.org/whl/cpu
RUN pip install --no-cache-dir -r requirements.txt

COPY . /app
EXPOSE 8080 8501

HEALTHCHECK --interval=30s --timeout=10s --retries=3 \
    CMD curl -f http://localhost:8080/api/model-info || exit 1

CMD ["python", "app.py"]

Bước 3: Tự động hóa Giao vận CD Đẩy Image lên Docker Hub

  docker-cd-pipeline:
    name: "CD: Build Docker Image & Public to Docker Hub"
    needs: ai-ci-pipeline
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    steps:
      - uses: actions/checkout@v4
      - uses: docker/setup-buildx-action@v3
      - uses: docker/login-action@v3
        with:
          username: ${{ secrets.DOCKERHUB_USERNAME }}
          password: ${{ secrets.DOCKERHUB_TOKEN }}
      - uses: docker/build-push-action@v6
        with:
          context: .
          push: true
          tags: ${{ secrets.DOCKERHUB_USERNAME }}/timexer-dinov3-ai:latest

Bước 4: Lệnh Thực Thi & Kiểm Thử Dành Cho Giảng Viên / Người Dùng

Bất kỳ ai cũng có thể kéo Image đã public và khởi chạy hệ thống ngay lập tức:

# 1. Kéo Image công khai từ Docker Hub
docker pull thuanhoa1110/timexer-dinov3-ai:latest

# 2. Khởi chạy Container Model Serving (Port 8080)
docker run -d -p 8080:8080 --name weather_ai thuanhoa1110/timexer-dinov3-ai:latest

# 3. Kiểm tra thông tin mô hình qua API
curl http://localhost:8080/api/model-info
